# 七界厨房 · 第一版存档

这是修改游戏主菜单之前保存的第一版，独立保留原有视觉与交互。七种主题、300 道完整食谱的生日料理网站。配方不主动加入乳制品，包含中文与英国食材名称、完整烹饪步骤和本地料理工具。

## 本机打开

依赖已安装时，双击 `start-local.cmd`，或在本目录运行：

```powershell
npm run dev
```

打开 **http://127.0.0.1:5176/**。终端保持运行；按 Ctrl+C 停止。服务只监听本机。

从源码包重新安装时，使用已验证的 Node.js 24：

```powershell
npm ci --offline=false --cache .npm-cache
npm run dev
```

## 构建与验收

```powershell
npm test
npm run validate:data
npm run build
npm run preview
```

构建目录为 `dist/`；生产预览地址 **http://127.0.0.1:4187/**。不要直接双击 HTML：浏览器对本地文件模块有限制。

浏览器验证需要先运行 `npm run dev`。默认使用本机安装的 Chrome；其他位置可通过 `CHROME_PATH` 环境变量指定：

```powershell
npm run test:browser
node scripts/audit-all-recipes.mjs
node scripts/browser-review.mjs
```

验收结果和截图保存在 `qa/`。截图脚本默认访问本机；可通过 `REVIEW_URL` 指定已部署站点。验收摘要见 [QA 报告](qa/QA_REPORT.md)。

## 内容与操作

| 主题 | 菜谱分类 | 完整条数 |
| --- | --- | ---: |
| 森林之子 | 晋菜与山西面食 | 50 |
| CS:GO | 川菜 | 50 |
| 三角洲 | 湘菜 | 40 |
| 绝地求生 | 鲁菜 | 40 |
| Apex | 粤菜 | 40 |
| 艾尔登法环 | 江浙菜 | 40 |
| 幻兽帕鲁 | 简易西餐 20 + 小甜点 20 | 40 |

- 顶部搜索跨全部菜系，支持中文菜名及中英文食材名。方向键选择结果，Enter 打开，Escape 关闭。未在输入框时按 `/` 聚焦搜索。
- 菜系内可按关键词、总时间、难度、收藏筛选。
- 食谱可调整人数、勾选食材、查看完整步骤、器具、熟度、替代方案、失误处理、保存和引用来源。
- 份量仅换算食材数量；步骤文字保留原方，分次用量显示换算比例。锅具、分批、时间、温度和单个成形尺寸不能机械放大。
- 采购篮合并相同英文食材名与单位；克和毫升不会自动互换。可勾选、调整人数、移除、复制或导出文字清单。
- 收藏、采购、步骤进度与计时保存在当前浏览器。无账户、云同步、后台服务或发送消息功能。
- 计时按实际截止时刻恢复。页面关闭时不会主动通知；带明确等待字段的步骤使用等待时间，并区分动手时间。
- 系统减少动态设置优先；页脚可关闭场景动态或改回系统鼠标。触屏使用原生触控。

## 文件布局

```text
src/main.js                 导航、搜索、面板与交互
src/themes.js               七种独立场景构图
src/motion.js               环境动画、场景状态与主题指针
src/domain.js               份量、合并采购、搜索、存储和计时逻辑
src/recipe-view.js          完整食谱与步骤阅读
src/data/recipes/all.json   唯一正式 300 道冻结食谱源
src/data/sources.json       来源目录
public/art/                七张原创生成场景
scripts/                   数据校验与浏览器验收
tests/                     逻辑和浏览器测试
docs/                      内容、素材与部署说明
qa/                        可重现验收报告
dist/                      构建后的静态站点
```

正式数据 SHA-256：`247c304aa21a9523cc6b6290a7a4cac759e126130e68eb2cc14483b668f792e6`。构建会检查精确分类数量、ID、必需字段、食材引用、来源、选定过敏原规则以及完全重复做法。

配方经过资料编审与独立内容审查，未逐道厨房试做；具体品牌的配料和交叉接触标签需购买时核对。研究素材中的游戏截图仅作设计参考，不进入 `dist/`。正式场景为原创生成插画，不冒充真实试做照片。

## GitHub Pages
